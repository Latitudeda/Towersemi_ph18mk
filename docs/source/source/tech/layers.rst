layers.py
==============

The layers are auto-generated by filling the ``layers.csv`` file, ``FLYLINE_MARK`` / ``ERROR_MARK`` layer are defined by **Latitudeda** for error display.

::

    class LAYER(BASE_LAYER):
        swg = Layer(PROCESS.swg, PURPOSE.drawing, 'Strip waveguide')
        rwg = Layer(PROCESS.rwg, PURPOSE.drawing, 'ridge waveguide')
        revswg = Layer(PROCESS.revswg, PURPOSE.drawing, 'reverse strip WG')
        nwg = Layer(PROCESS.nwg, PURPOSE.drawing, 'nitride waveguide')
        revnwg = Layer(PROCESS.revnwg, PURPOSE.drawing, 'Reverse nitride WG')



For users using layout viewers (e.g. KLayout), they can import the layer properties file ``layers.lyp`` in the file folder.
