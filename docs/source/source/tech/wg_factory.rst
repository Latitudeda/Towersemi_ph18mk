factory.py
===============


Define the straight and bend waveguide factories for auto-routing function in **PhotoCAD**.

#. ``StraightFactory`` : Import the straight waveguide to use it for straight connection.

#. ``CircularBendFactory`` : Import ``BendCircular``, ``BendCircular90``, ``BendCircular90_Strip_C_WIRE_TE``, ``BendCircular90_Strip_C_WIRE_TM``, ``BendCircular90_Strip_O_WIRE_TE``, ``BendCircular90_Strip_O_WIRE_TM``, ``BendCircular90_SiN_C_WIRE_TE``, ``BendCircular90_SiN_C_WIRE_TM``, ``BendCircular90_SiN_O_WIRE_TE``, ``BendCircular90_SiN_O_WIRE_TM``, ``BendCircular90_Ridge_C_WIRE_TE``, ``BendCircular90_Ridge_C_WIRE_TM``, ``BendCircular90_Ridge_O_WIRE_TE``, ``BendCircular90_Ridge_O_WIRE_TM`` from ``bend_circular`` and assigned each component to different situations.
