__init__.py
===================

Define the WG class which consists of ``Strip.C.WIRE_TE``, ``Strip.C.WIRE_TM``, ``Strip.O.WIRE_TE``, ``Strip.O.WIRE_TM``, ``Ridge.C.WIRE_TE``, ``Ridge.C.WIRE_TM``, ``Ridge.O.WIRE_TE``, ``Ridge.O.WIRE_TM``, ``SiN_strip.C.WIRE_TE``, ``SiN_strip.C.WIRE_TM``, ``SiN_strip.O.WIRE_TE`` and ``SiN_strip.O.WIRE_TM`` class. The width of the waveguide is set here according the parameters in ``constant.py`` file. **PhotoCAD** also support CD bias control of the waveguide width. The CD bias setting can be implemented in ``strip.py``, ``ridge.py`` and ``SiN_strip.py`` .
