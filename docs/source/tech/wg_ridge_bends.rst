ridge_bends.py
======================

Define the bend settings for each waveguide(`Ridge.C.WIRE_TE & Ridge.C.WIRE_TM & Ridge.O.WIRE_TE & Ridge.O.WIRE_TM`).

* ``Ridge_C_BENDS``

    * ``FOR_WIRE_TE``

        * Note that the default bend radius for every 90-degree ``BEND_CIRCULAR`` used for auto-routing is set to a recommended value of 15 um.

    * ``FOR_WIRE_TM``

        * Note that the default bend radius for every 90-degree ``BEND_CIRCULAR`` used for auto-routing is set to a recommended value of 25 um.

* ``Ridge_O_BENDS``

    * ``FOR_WIRE_TE``

        * Note that the default bend radius for every 90-degree ``BEND_CIRCULAR`` used for auto-routing is set to a recommended value of 15 um.

    * ``FOR_WIRE_TM``

        * Note that the default bend radius for every 90-degree ``BEND_CIRCULAR`` used for auto-routing is set to a recommended value of 25 um.
